# Bookie Voice Desk

A static, Vercel-ready sports betting voice assistant.

What it does:

- listens to a call via browser speech recognition
- keeps a live transcript
- drafts and tracks bets
- surfaces risk flags, line notes, and bankroll guardrails

Notes:

- Use it only with consent and in compliance with local recording laws.
- This app organizes and reviews bets. It does not guarantee outcomes.
- Best experience is on Chromium-based browsers over HTTPS.

Deploy:

```bash
vercel --prod --yes
```
